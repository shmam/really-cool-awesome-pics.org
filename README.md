# [really-cool-awesome-pics.org](https://really-cool-awesome-pics.org/)

a photo blog by sam crochet, who sometimes shoots some 35mm photos.
built using nextjs and cloudflare workers. Images serves using cloudflare R2.

Exporting photos at 2000x1341 in .avif format with hdr and rec 2020 color profile. 
File format should be `YYYYMMDD-DevelopedOrder#-FilmStockAndISO-IDNumber.avif` like `20241002-RFL68936-Portra400-00040.avif`.
